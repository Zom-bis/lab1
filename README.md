# ЛР1. Калькулятор и конвертер величин

Программа для командной строки: считает арифметические выражения и переводит
величины из одних единиц в другие. Сделаны основные требования и все
дополнительные задания.

## Установка

Клонировать репозиторий
1.В самом IDE через URL
2.Через git clone <ссылка>

Активировать окружение
.\.venv\Scripts\activate

Из папки lab_01:

    python -m pip install -e ".[dev]"

## Запуск

    python -m toolkit --help
    python -m toolkit calc "2 + 3 * 4"
    python -m toolkit calc "(2 + 3) * 4"
    python -m toolkit calc "2 * -3" --rpn
    python -m toolkit convert 1000 --from mm --to m
    python -m toolkit convert 0 --from c --to f
    python -m toolkit history
    python -m toolkit history --clear

Если выражение начинается с минуса, его нужно писать после двух дефисов:
python -m toolkit calc -- "-7 // 2". Иначе argparse считает его опцией.

При успехе программа завершается с кодом 0. При ошибке ввода пишет сообщение
в stderr и завершается с кодом 2.

## Калькулятор

Поддерживаются целые и дробные числа, операции + - * / // %, унарный плюс
и минус, скобки. Пробелы между символами не важны. Умножение и деление
выполняются раньше сложения и вычитания. eval и exec не используются.

Вычисление идёт в четыре шага, все они в calculator.py:

1. tokenization разбивает строку на числа, операторы и скобки.
2. validation проверяет, что числа и операторы чередуются правильно и скобки
   парные. Минус, который стоит там, где ожидается число, считается унарным
   и заменяется на "~".
3. to_rpn переводит выражение в обратную польскую запись рекурсивным спуском
   (класс RpnParser). Грамматика:

       expression = term (("+" | "-") term)*
       term       = unary (("*" | "/" | "//" | "%") unary)*
       unary      = "~" primary | primary
       primary    = число | "(" expression ")"

4. calculation считает обратную польскую запись с помощью стека.

Пример для 2*-3: токены 2, *, -, 3. После * ожидается число, поэтому минус
унарный. Обратная польская запись: 2 3 ~ *. Стек: [2], [2, 3], [2, -3], [-6].

Вычисления идут в Decimal с точностью 28 значащих цифр и округлением
ROUND_HALF_EVEN. Поэтому 0.1 + 0.2 = 0.3, а 2 / 3 = 0.6666666666666666666666666667.

Целочисленное деление // отбрасывает дробную часть: 7 // 2 = 3, -7 // 2 = -3.
Остаток % имеет знак делимого: -7 % 2 = -1, 7 % -2 = 1. При этом всегда
a = b * (a // b) + a % b.

Ошибки: пустое выражение, недопустимый символ, неверное число, пропущен
операнд, пропущен оператор, два оператора подряд, ошибки со скобками,
деление на ноль.

## Конвертер

Единицы: длина mm, cm, m, km; масса g, kg; температура c, f, k. Регистр не
важен. Переводить между разными группами нельзя, температура ниже абсолютного
нуля считается ошибкой. Результат возвращается как float.

Таблица единиц лежит в src/units.json. Для длины и массы там записано, сколько
метров или килограммов в одной единице. Чтобы добавить новую единицу длины,
достаточно дописать её туда, например "dm": 0.1.

Можно указать свой файл с таблицей через --units:

    python -m toolkit convert 2 --from m --to dm --units my_units.json

Файл my_units.json нужно сначала создать в том же формате, что src/units.json.

## История

Каждое успешное вычисление сохраняется в файл .toolkit_history.json в домашней
папке. Путь можно поменять через переменную окружения TOOLKIT_HISTORY.
Команда history показывает историю, history --clear очищает её.
